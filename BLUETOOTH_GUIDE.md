# Руководство по Bluetooth соединению

## Обзор проблемы

В предыдущих версиях приложения мы пытались реализовать кастомный UI для выбора Bluetooth устройств, что привело к следующим проблемам:

1. **Проблемы с отображением имен устройств** - показывались только MAC-адреса
2. **Ошибки при соединении** - нестабильные подключения
3. **Сложная фильтрация** - проблемы с UUID и manufacturer data

## Новый подход

Мы перешли на **гибридный подход**, который сочетает:

1. **Автоматическое сканирование** - поиск всех доступных устройств
2. **Умная фильтрация** - автоматическое определение устройств с нашим приложением
3. **Упрощенное соединение** - более надежная логика подключения
4. **Нативный выбор** - кнопка для быстрого поиска устройств

## Как это работает

### 1. Автоматическое сканирование
- При запуске приложения автоматически начинается поиск устройств
- Все найденные устройства отображаются в списке
- Устройства с нашим приложением помечаются специально

### 2. Фильтрация устройств
Устройство считается "нашим", если в его advertisement data присутствует:
- Сервис UUID: `0000a7c0-0000-1000-8000-00805f9b34fb`
- Или короткая форма: `a7c0`

### 3. Улучшенное отображение имен
- Приоритет: `platformName` → `advertisementName` → короткий MAC
- Кэширование имен для быстрого отображения
- Автоматическое обновление при получении новой информации

### 4. Нативный поиск устройств
- Кнопка "Найти устройства" запускает быстрый поиск
- Автоматический выбор первого найденного устройства с нашим приложением
- Подтверждение подключения через диалог

## Использование

### Обычный режим
1. Запустите приложение
2. Дождитесь автоматического поиска устройств
3. Выберите устройство из списка
4. Нажмите "Пригласить"

### Быстрый режим
1. Нажмите кнопку "Найти устройства"
2. Подтвердите подключение к найденному устройству
3. Устройство автоматически выбирается в списке

## Отладка

В debug режиме в консоли отображается подробная информация:
- `[SCAN]` - информация о найденных устройствах
- `[ADD]` - добавление новых устройств
- `[UPDATE]` - обновление информации об устройствах
- `[CACHE]` - обновление из кэша

## Преимущества нового подхода

1. **Надежность** - более стабильные соединения
2. **Простота** - меньше кода, меньше ошибок
3. **Производительность** - быстрый поиск и отображение
4. **UX** - понятный интерфейс для пользователя

## Возможные улучшения

1. **Диалог выбора** - показать список найденных устройств для выбора
2. **Автоматическое переподключение** - при разрыве соединения
3. **Статус соединения** - индикатор качества связи
4. **Групповые игры** - поддержка нескольких игроков

## Технические детали

### UUID сервиса
- Полный: `0000a7c0-0000-1000-8000-00805f9b34fb`
- Короткий: `a7c0`

### Таймауты
- Подключение: 10 секунд
- Обнаружение сервисов: 5 секунд
- Сканирование: 3 секунды

### Разрешения
- `bluetoothScan` (Android 12+)
- `bluetoothConnect` (Android 12+)
- `bluetoothAdvertise` (Android 12+)
- `locationWhenInUse` (для BLE сканирования)
