# BaTuGa - Игра по Bluetooth

Мобильное приложение BaTuGa для игры в крестики-нолики между двумя игроками через Bluetooth соединение.

## Описание

Приложение позволяет двум игрокам соединиться по Bluetooth и играть в классическую игру крестики-нолики, каждый на своем смартфоне. Игроки могут видеть друг друга в списке доступных устройств, приглашать в игру и наслаждаться полноценной игрой с синхронизацией ходов в реальном времени.

## Архитектура

Проект построен с использованием архитектурных принципов:

- **Feature-first подход**: код организован по функциональным модулям
- **BLoC паттерн**: для управления состоянием приложения
- **Dependency Injection**: через пакет `dep_gen`
- **Freezed**: для генерации immutable классов
- **SOLID принципы**: для обеспечения качества кода

## Функциональность

### Основные экраны

1. **Сплэш-скрин**: Загрузка и инициализация приложения
2. **Главный экран**: 
   - Список доступных игроков
   - Диалог ввода псевдонима (при первом запуске)
   - Приглашение в игру
3. **Экран игры**:
   - Игровое поле 3x3
   - Индикация текущего хода
   - Отображение результата игры

### Bluetooth функциональность

- Автоматический поиск устройств с приложением
- Установка Bluetooth соединения
- Синхронизация игровых данных
- Обработка разрыва соединения

### Игровая логика

- Случайный выбор первого игрока
- Валидация ходов
- Определение победителя
- Обработка ничьей

## Технологии

- **Flutter**: 3.8.1+
- **Dart**: 3.8.1+
- **flutter_bluetooth_serial**: для Bluetooth соединения
- **flutter_bloc**: для управления состоянием
- **freezed**: для генерации кода
- **dep_gen**: для dependency injection
- **shared_preferences**: для локального хранения

## Установка и запуск

1. Клонируйте репозиторий:
```bash
git clone <repository-url>
cd batuga
```

2. Установите зависимости:
```bash
flutter pub get
```

3. Запустите приложение:
```bash
flutter run
```

## Разработка

### Генерация кода

Для генерации кода Freezed выполните:
```bash
flutter packages pub run build_runner build
```

### Архитектурные правила

Проект следует строгим архитектурным правилам, описанным в папке `.cursor/rules/`. Все новые компоненты должны соответствовать установленным стандартам.
