# BaTuGa (в разработке)

Мобильное приложение для оффлайн игр между двумя игроками через Bluetooth-соединение (BLE).

## Готовность

- Логика транспорта данных. Особенности:
  - роли: сервер - ждет, клиент - ищет и подключается; 
  - логика авторизации клиента на сервере (принял/отказал);
  - возможность прервать соединение любым участником;
  - стабильный двусторонний обмен стандартизированными сообщениями.
- Сплэш экран
- Главный экран
- Диалоги сервера (в разработке)
- Диалоги клиента (в разработке)
- Экран списка игр (в разработке)

## Особенности

- Игры по Bluetooth между двумя устройствами (крестики-нолики, морской бой и др.)
- Автоматическое обнаружение устройств с приложением
- Не нужен интернет
- Обеспечивает соединение между Android-Android, iOS-iOS, Android-iOS
- Простой и интуитивно понятный интерфейс

## Технологии

- Flutter 3.8.1+
- Dart 3.8.1+
- Bluetooth Low Energy (BLE)
- BLoC для управления состоянием
- Freezed для неизменяемых моделей
- dep_gen для внедрения зависимостей

## Установка и запуск

1. Клонируйте репозиторий:
   ```bash
   git clone <repository-url>
   cd bluetooth_toe
   ```

2. Установите зависимости:
   ```bash
   flutter pub get
   ```

3. Сгенерируйте необходимые файлы:
   ```bash
   flutter packages pub run build_runner build
   flutter pub run dep_gen:generate -p lib/core/di
   ```

4. Запустите приложение:
   ```bash
   flutter run
   ```

## Структура проекта

```
lib/
├── core/                   # Общие модули
│   ├── config/             # ENV-файлы
│   ├── constants/          # Константы приложения
│   ├── data/               # Слой данных (DTO, провайдеры, транспорт)
│   ├── di/                 # Внедрение зависимостей
│   ├── domain/             # Доменные модели и абстракции над слоем данных
│   ├── extensions/         # Расширения Dart
│   ├── presentation/       # Глобальные виджеты и др. элементы UI
│   ├── resources/          # Классы-библиотеки ссылок на ресурсы приложения (изображения, анимации и др.)
│   ├── ыукмшсуы/           # Вспомогательные сервисы (логгер, управление разрешениями и BT-адаптером)
│   ├── themes/             # Темы приложения
│   └── utils/              # Утилиты (мелкие вспомогательные классы)
├── features/               # Функциональные модули
│   ├── chat/               # Чат (скрыт)
│   ├── splash/             # Заставка
│   ├── home/               # Главный экран
│   ├── games_list/         # Список игр
│   └── tictactoe/          # Игра крестики-нолики
└── main.dart              # Точка входа
```
