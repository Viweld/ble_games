# BaTuGa - Bluetooth Tic-Tac-Toe

Мобильное приложение для игры в крестики-нолики между двумя игроками через Bluetooth-соединение.

## Особенности

- Игра в крестики-нолики по Bluetooth между двумя устройствами
- Автоматическое обнаружение устройств с приложением
- Реальное время игровой синхронизации
- Простой и интуитивно понятный интерфейс

## Технологии

- Flutter 3.8.1+
- Dart 3.8.1+
- Bluetooth Low Energy (BLE)
- BLoC для управления состоянием
- Freezed для неизменяемых моделей
- dep_gen для внедрения зависимостей

## Установка и запуск

1. Клонируйте репозиторий:
   ```bash
   git clone <repository-url>
   cd bluetooth_toe
   ```

2. Установите зависимости:
   ```bash
   flutter pub get
   ```

3. Сгенерируйте необходимые файлы:
   ```bash
   flutter packages pub run build_runner build
   flutter pub run dep_gen:generate -p lib/core/di
   ```

4. Запустите приложение:
   ```bash
   flutter run
   ```

## Тестирование Bluetooth-соединения

Для тестирования Bluetooth-соединения и обмена сообщениями между устройствами:

1. Откройте приложение
2. Выберите "Тест Bluetooth-соединения" в главном меню
3. Следуйте инструкциям на экране

Подробное руководство по тестированию находится в файле [BLUETOOTH_TESTING_GUIDE.md](BLUETOOTH_TESTING_GUIDE.md)
