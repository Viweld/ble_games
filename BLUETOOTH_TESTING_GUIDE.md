# Руководство по тестированию Bluetooth-соединения

## Подготовка к тестированию

1. Убедитесь, что оба устройства имеют:
   - Включенный Bluetooth
   - Разрешения на использование Bluetooth для приложения
   - Доступ к местоположению (необходимо для сканирования Bluetooth)

2. Установите приложение на оба устройства

3. Запустите приложение на обоих устройствах

## Тестирование соединения

### Шаг 1: Настройка сервера (устройство 1)
1. Откройте приложение
2. Нажмите "Ожидать присоединения"
3. Устройство станет видимым для других устройств

### Шаг 2: Поиск и подключение (устройство 2)
1. Откройте приложение
2. Нажмите "Найти и подключиться"
3. Дождитесь появления первого устройства в списке
4. Выберите устройство из списка
5. Нажмите "Подключиться"

### Шаг 3: Проверка соединения
1. После успешного подключения откроется экран обмена сообщениями
2. Введите тестовое сообщение и нажмите "Отправить"
3. Проверьте, что сообщение отображается на обоих устройствах

## Возможные проблемы и их решения

### Проблема: Устройства не находят друг друга
**Решения:**
- Убедитесь, что оба устройства находятся на расстоянии менее 10 метров
- Перезапустите Bluetooth на обоих устройствах
- Повторите процесс поиска
- Проверьте разрешения приложения

### Проблема: Ошибка подключения
**Решения:**
- Убедитесь, что серверное устройство находится в режиме ожидания
- Проверьте, что оба устройства используют одну версию приложения
- Перезапустите приложения на обоих устройствах

### Проблема: Сообщения не отправляются
**Решения:**
- Проверьте, что соединение установлено (иконка Bluetooth в строке состояния)
- Приложение автоматически пытается восстановить соединение при ошибках
- Переподключитесь к устройству
- Проверьте логи приложения на наличие ошибок

**Автоматическое восстановление:**
- При возникновении ошибок соединения приложение автоматически пытается сбросить и восстановить соединение
- В случае ошибки статуса 133 приложение автоматически выполняет сброс соединения

### Проблема: Ошибка статуса 133 (GATT_ERROR)
**Описание:** Эта ошибка часто возникает в Android при работе с Bluetooth LE и указывает на проблемы с GATT-соединением. Обычно это происходит из-за:
- Кэширования GATT-базы данных
- Нестабильного соединения
- Попытки записи сразу после обнаружения сервисов
- Превышения размера MTU (Maximum Transmission Unit)
- Использования неподходящего типа записи (withResponse vs withoutResponse)

**Решения:**
- Приложение автоматически пытается сбросить соединение при обнаружении этой ошибки
- Если автоматический сброс не помог, полностью отключитесь от устройства и подключитесь заново
- Перезапустите Bluetooth на обоих устройствах
- Перезапустите приложения на обоих устройствах
- Если проблема повторяется, перезагрузите устройства

**Технические детали:**
- Ошибка статуса 133 является общей ошибкой Bluetooth LE в Android
- Приложение теперь автоматически обнаруживает эту ошибку и пытается выполнить сброс соединения
- Пользователю предлагается переподключиться к устройству для восстановления стабильного соединения
- Приложение теперь:
  - Добавляет небольшую задержку после обнаружения сервисов
  - Использует writeWithoutResponse для отправки сообщений
  - Запрашивает увеличенный MTU при подключении
  - Проверяет свойства характеристик перед использованием
  - Логирует размер сообщений для диагностики

## Логирование и отладка

Приложение выводит подробные логи Bluetooth-операций в консоль:
- `[Bluetooth]` - информационные сообщения
- `[Bluetooth ERROR]` - ошибки

Для просмотра логов используйте:
```bash
flutter logs
```

## Тестирование различных сценариев

### Сценарий 1: Обычное подключение
1. Устройство A: режим сервера
2. Устройство B: режим клиента
3. Подключение и обмен сообщениями

### Сценарий 2: Потеря соединения
1. Установите соединение
2. Отправьте несколько сообщений
3. Отключите Bluetooth на одном из устройств
4. Проверьте обработку ошибок
5. Восстановите соединение

### Сценарий 3: Многократное подключение
1. Подключитесь и обменяйтесь сообщениями
2. Отключитесь
3. Повторите подключение
4. Убедитесь, что соединение устанавливается корректно

## Рекомендации по тестированию

1. **Тестирование на разных устройствах**: Проверьте работу на устройствах с разными версиями Android
2. **Тестирование на расстоянии**: Проверьте стабильность соединения на разных расстояниях
3. **Тестирование при помехах**: Проверьте работу в условиях радиопомех
4. **Тестирование энергопотребления**: Оцените влияние Bluetooth-соединения на расход батареи
